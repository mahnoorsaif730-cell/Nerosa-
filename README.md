# 💊 Nerosa — AI Medicine Information Assistant

Nerosa is an AI-powered medicine information assistant designed to provide clear, accessible, and safety-focused information about medicines.

## 🎯 Project Goal

The goal of Nerosa is to make basic medicine information easier to understand while encouraging safer decision-making and appropriate professional consultation.

## ✨ Key Features

- 🔎 **Medicine Information Retrieval** — Retrieves relevant medicine information from the project dataset.
- 🛡️ **Safety & Risk Detection** — Classifies situations as low, moderate, or emergency.
- 📷 **Medicine Image Identification** — Uses OCR to identify a medicine name from an uploaded image.
- 💬 **AI Assistant** — Provides an interactive interface for medicine-related informational questions.
- 📚 **Source References** — Provides references for medicine information.
